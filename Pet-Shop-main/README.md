# 🐶 PetShop - Máquina de Banho (Java)

## 📝 Descrição
Este projeto é uma aplicação em **Java (console)** que simula o funcionamento de uma **máquina automática de banho para pets**.  
O usuário interage com o sistema por meio de um menu no terminal, podendo adicionar água e shampoo, colocar ou remover o pet da máquina, dar banho e verificar o estado atual da máquina.

O projeto foi desenvolvido com foco no estudo de **abstração, orientação a objetos e controle de fluxo**, sendo ideal para aprendizado e portfólio iniciante.

---

## 🚀 Funcionalidades
- Dar banho no pet
- Abastecer a máquina com água
- Abastecer a máquina com shampoo
- Verificar quantidade de água disponível
- Verificar quantidade de shampoo disponível
- Verificar se há um pet na máquina
- Colocar um pet na máquina
- Remover o pet da máquina
- Limpar a máquina
- Menu interativo no terminal

## 📋 Menu de Opções

Ao executar o programa, o usuário pode escolher dentre as seguintes opções:

1 - Dar banho no pet
2 - Abastecer a máquina com água
3 - Abastecer a máquina com shampoo
4 - Verificar quantidade de água
5 - Verificar quantidade de shampoo
6 - Verificar se há pet na máquina
7 - Colocar o pet na máquina
8 - Remover o pet da máquina
9 - Limpar a máquina
0 - Sair

## 📌 Regras de Funcionamento

- Não é possível dar banho sem água ou shampoo

- O pet precisa estar dentro da máquina para tomar banho

- A máquina pode ser limpa manualmente

- Todas as interações acontecem via terminal
